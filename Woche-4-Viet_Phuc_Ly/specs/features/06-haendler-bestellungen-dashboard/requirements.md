# Feature 06 – Requirements

## Bestellübersicht
- Nur Bestellungen der eigenen Shops; fremde IDs → 404.
- Pro Bestellung: Nummer, Datum/Uhrzeit, Kunde + Ort, Shop, Anzahl Bücher, Summe; aufgeklappt Positionen, Lieferadresse, Status.
- Statuswechsel aktualisiert die Liste sofort; ungültiger Status → 400.
- Versandlabel-Download für jede Bestellung.

## Dashboard
- Zeitraum 7 / 30 / 90 Tage umschaltbar.
- Kennzahlen: Umsatz, Anzahl Bestellungen, verkaufte Bücher, Ø Bestellwert, offene Bestellungen (Link zur Bestellliste).
- Diagramm Umsatz pro Tag (alle Tage des Zeitraums), Diagramm Top-10-Bücher nach Umsatz, Tabelle aller Bücher.
